# Fictional buying policy

Version 1.0. Synthetic demonstration policy, not a commercial agreement.

## Purchasing constraints
Review inventory every seven days. Service levels are 90%, 95% or 99%.
Round positive purchases to pack size and respect the minimum order per SKU.
Use GBP; budgets apply across SKUs at each review. Allocation is a heuristic,
not a guaranteed optimum. Accepted recommendations create plans, not real orders.
